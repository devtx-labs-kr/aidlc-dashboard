# 파서 골든 픽스처

이 디렉터리의 `*.txt` 파일은 `/usage` 출력 파싱을 결정적으로 검증하기 위한 골든 픽스처다.

**주의 — 민감 데이터 취급 (team-practices 보안 관행):**
- 이 픽스처는 실제 계정 데이터가 아닌 **합성(synthetic) 예시**이거나, 실제 캡처라면 계정
  식별자·토큰·이메일 등 민감 값을 **마스킹(redact)한 뒤** 저장한 것이다.
- `/usage` 원문을 그대로(민감 값 포함) 커밋하지 않는다(NEVER).
- 여기의 숫자·플랜명·날짜는 모두 예시용 더미 값이다.

파서 테스트(`../usage-parser.test.ts`)는 CLI를 호출하지 않고 이 문자열을 입력으로 받는다.
